# コア層（サーバー非依存ロジック）

`minecraft_server_spec.md` のうち、**Minecraft のサーバーを起動せずに実装・検証できる部分**。
Bukkit / Paper API への依存を一切持たない純粋な Java であり、`javac` だけで動く。

## 実行

```sh
./run-tests.sh                     # 検証（1245件）
./simulate-knight.sh 20 8 80       # 騎士型の戦闘をオフラインで再現
./generate-pack.sh                 # リソースパックの雛形を骨格から生成
./dump-rig.sh 1 0                  # 表示へ送るべき配置（実機の /raid dump と比べる）
```

`simulate-knight.sh` の引数は「参加人数・1人あたりDPS・被ダメ軽減%」。Minecraft を起動せずに、
段階移行・被弾・討伐時間・モーションのサンプリング・通信量を確認できる。

外部ライブラリを取得しないため、ネットワークもビルドツールも不要である。

## 設計上の判断

- **pitch は累積せず真偽で保持する。** 仕様は「総変化量が0なら非計上」と書くが、値は判定に使われない
- **`ActivityWindow.advance` は窓長より十分短い間隔で呼ぶ。** 変化の有無は窓ごとに独立して評価されるため、複数の窓を一度に進めると最初の窓しか計上されない
- **領土の連結性は直交隣接で判定する。** 隣接要件（§4.10）に合わせた。解放順序の距離はチェビシェフ距離（§4.7 の規定どおり）
- **境界接触面は「直交4方向のうち自国領土でないものの数」と解釈した。** 外側へ突出しているチャンクほど大きくなる
- **貢献度の納入分に上限を置いた。** 上限がなければ役職の自動就任（§6.1）と統一時の自動離脱順（§8.3）を資金で操作できる
