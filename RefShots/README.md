# 撮影した参照画像の置き場

`RefShots/{図鑑番号}/` に画像を入れてください（例: `RefShots/110/front.png`）。
ファイル名は自由ですが、`front`(正面) `side`(真横) `back`(背面) `diag`(斜め前) のどれかが分かる名前だと助かります。1種につき1〜4枚。
番号が分からない場合は日本語名のフォルダでも構いません（例: `RefShots/モコロン/`）。
