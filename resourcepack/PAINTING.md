# 塗り絵の描き方（Windows のペイントだけで足りる）

立体を扱う道具は要らない。**箱の形・向き・UV は骨格データから自動生成してある**ので、
描く側の仕事は `assets/minecraft/textures/knight/*.png` を**塗り替えるだけ**である。

---

## 1. 何を塗るのか

11枚ある。**左右の腕・角・肩、両形態の同じ部位は1枚を共有する**（寸法差は UV の伸びに吸収させる）。

| ファイル | 貼られる部位 | 枠の並び | 前面の枠 |
|---|---|---|---|
| `torso.png` | 第一形態の胴・第二形態の人胴 | 縦積み | 44×50 |
| `head.png` | 頭（両形態） | 縦積み | 43×42 |
| `horn.png` | 左右の角（両形態） | 横並び | 17×111 |
| `crest.png` | 頭飾り（両形態） | 縦積み | 43×42 |
| `shoulder.png` | 左右の肩（両形態） | 縦積み | 53×39 |
| `arm.png` | 左右の腕（両形態） | 横並び | 32×84 |
| `leg.png` | 第一形態の左右の足 | 横並び | 32×87 |
| `spear.png` | 槍の柄（両形態） | 横並び | 21×107 |
| `spearhead.png` | 穂先（両形態） | 縦積み | 43×42 |
| `horse_body.png` | 馬胴 | 縦積み | 28×22 |
| `horse_leg.png` | 馬の前足・後足 | 横並び | 27×101 |

どの枠も**最低17画素**あり、バニラのブロック（16画素）より細かく描ける。

---

## 2. 枠の読み方

1枚の中に6つの枠がある。**枠の左上に面の頭文字が入っている**ので、並びを覚える必要はない。

| 文字 | 面 | 描く絵 |
|---|---|---|
| `F` | 前（Front） | 正面から見た絵。顔・胸の紋章はここ |
| `B` | 後（Back） | 背面から見た絵 |
| `R` | 右（Right） | **個体から見た右**。正面から見ると左側 |
| `L` | 左（Left） | 個体から見た左 |
| `U` | 上（Up） | 真上から見た絵。北（前方）が枠の上 |
| `D` | 下（Down） | 真下から見た絵 |

枠の中の向きは **その面を外から見たまま**である。前面の枠に顔を描けば前を向く。

**濃い灰色の余白はどの面にも貼られない。** 塗っても見た目に出ないし、塗らなくても問題ない。

枠の並べ方は画像によって2通りある（画素を大きく取れるほうを生成側が選ぶ）。

```
  横並び                          縦積み
       ┌────┬────┐               ┌────┬────┐
       │ U  │ D  │               │ U  │ D  │
  ┌────┼────┼────┼────┐          ├────┼────┤
  │ R  │ F  │ L  │ B  │          │ R  │ L  │
  └────┴────┴────┴────┘          ├────┼────┤
                                 │ F  │ B  │
                                 └────┴────┘
```

## 3. ペイントでの手順

1. `E:\raid-dev\resourcepack\assets\minecraft\textures\knight\torso.png` を**右クリック → プログラムから開く → ペイント**
2. **表示 → ズーム**を 800% くらいまで上げる。**表示 → グリッド線**を入れると1画素が見える
3. 枠の中を塗る。下地は面ごとに明るさを変えてあるので、そのまま陰影として使ってよい
4. 元の色を拾いたいときは**スポイト**（色の選択）を使う
5. **Ctrl + S** で保存する。形式を訊かれたら **PNG のまま**にする

### 守ること

| 決め事 | 理由 |
|---|---|
| **画像の大きさ（128×128）を変えない** | 枠の座標が UV に焼き込まれている。サイズを変えると全部ずれる |
| **PNG 以外で保存しない** | JPEG は色がにじみ、BMP は Minecraft が読まない |
| **透明を使わない** | 古いペイントは α を残せない。箱は不透明で描く |
| **ファイル名を変えない** | モデルの `"skin"` がこの名前を指している |

> Windows 11 のペイント（レイヤー・透明あり）でも構わない。透明部分は黒くなるだけで壊れはしない。

### 原本に戻す

塗り直しに失敗したら `resourcepack/templates/` から同じ名前の PNG を写せばよい。
こちらは生成のたびに書き直される原本である。

```powershell
Copy-Item -Force E:\raid-dev\resourcepack\templates\torso.png `
                 E:\raid-dev\resourcepack\assets\minecraft\textures\knight\torso.png
```

## 4. 塗った絵を確かめる

```powershell
powershell -ExecutionPolicy Bypass -File E:\raid-dev\resourcepack\sync-pack.ps1
```

ゲーム内で:

```
F3 + T                  # リソースパックを読み直す
/raid model authored    # 描いたモデルで出し直す
/raid model vanilla     # バニラの素材と見比べる
/raid model             # いまどちらかを表示する
```

`/raid model authored` は**出ている個体をその場で作り直す**。骨格は個体を作るときに組むため、
出し直さないと切り替えが効かない。

サーバーを起動し直すとバニラの素材に戻る（既定値）。

---

## 5. うまくいかないとき

| 症状 | 原因 |
|---|---|
| 紙のまま出る | リソースパックが読み込まれていない。`README.md` の「効いていないときの切り分け」を見る |
| 紫と黒の欠損 | モデルの JSON が壊れている。`./core/generate-pack.sh` で作り直す |
| 白いままで絵が出ない | `/raid model authored` を実行していない（バニラの素材が出ている） |
| 絵が伸びている | その部位は共有した1枚を使っている。寸法差を UV の伸びで吸収しているためで、異常ではない |
| 絵が上下逆・左右逆 | 枠を取り違えている。目印の文字（F/B/R/L/U/D）で読み直す |
| 塗った絵が消えた | 生成では消えない。`templates/` から写し戻して塗り直す |

---

## 6. 生成し直すとき

骨格の寸法（`KnightDefinition`）を変えたら作り直す。

```sh
./core/generate-pack.sh
```

- モデルの JSON と振り分け、`templates/` の原本は**上書きされる**
- `assets/minecraft/textures/knight/*.png` は**触らない**（塗った絵を消さない）

寸法を変えると枠の大きさも変わるため、絵は伸び縮みする。大きく変えたときは
`templates/` の新しい原本と見比べて塗り直すのが早い。
