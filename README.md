# MysteryDungeonRoguelike

Godot 4.3 (C# / .NET) で開発している、不思議のダンジョン系ローグライクゲームです。
パーティを編成して拠点からダンジョンへ出撃し、ターン制のグリッド移動でフロアを攻略していきます。

## 動作環境

- Godot 4.3 (.NET版)
- .NET SDK 8.0
- 対応プラットフォーム: デスクトップ（開発中）/ Android（デバッグビルドをCIで自動生成）

## 主な実装済み機能

- **グリッド／ターン制システム**: グリッドベースの移動とターン進行の基盤
- **ダンジョン生成**: BSPアルゴリズムによる自動フロア生成、敵・オブジェクトの動的配置、モンスターハウス
- **視界・ミニマップ**: FOV（視界）システムとミニマップ表示
- **戦闘システム**: ステータス管理、タイプ相性、A*経路探索AI、技（わざ）システム、体当たり攻撃、撃破/死亡処理
- **パーティシステム**: パーティ追従AI、撃破数ベースの仲間加入、わざ自動使用の許可設定、拠点でのパーティ編成
- **インベントリ**: アイテムと効果の管理
- **移動仕様**: 8方向移動、角抜け制限、地形ごとの踏破プロファイル、水脈・溶岩などの地形生成
- **拠点(ハブ)**: 拠点マップと拠点強化のプログレッション、ダンジョン選択（出撃）システム
- **フロア進行**: 敵レベルスケーリング、ボス戦、ダンジョンクリア判定

## ディレクトリ構成

```
Scenes/           # HubScene, DungeonScene などのシーンファイル
Scripts/
  Core/           # ゲーム全体の基盤処理
  Grid/           # グリッド・座標系
  Turn/           # ターン進行管理
  Dungeon/        # ダンジョン生成・フロア管理
  Entities/       # プレイヤー・敵・NPCなどのエンティティ
  Combat/         # 戦闘・技システム
  Hub/            # 拠点・進行管理
  UI/             # ゲームUI
  Utils/          # 共通ユーティリティ
docs/architecture/  # アーキテクチャ設計書
.github/workflows/  # CI（Androidデバッグビルド自動化）
```

## ビルド・実行方法

1. Godot 4.3（.NET版）をインストール
2. 本リポジトリをGodotエディタで開く
3. `dotnet restore` でC#依存関係を復元
4. エディタから実行、またはエクスポート設定に従いビルド

Androidデバッグビルドは `.github/workflows/android_build.yml` によりpush時に自動生成されます。
