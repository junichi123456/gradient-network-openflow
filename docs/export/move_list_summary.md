# 技リスト仕様まとめ（Claudeチャット引き継ぎ用）

不思議のダンジョン系ローグライク（Godot / C#）の技データベースについて、
現在の確定仕様と、そこに至る調整の経緯をまとめたものです。

---

## 1. 現在の技リスト（確定）

**全581技 = 物理310 / 特殊213 / 変化58**

| 項目 | 内容 |
|---|---|
| 属性 | 無・炎・水・草・電・地・氷・竜・闇 の9属性 |
| 威力レンジ | 15〜180（すべて5の倍数） |
| 射程内訳 | Adjacent 392 / Line 54 / Room 31 / TwoTile 27 / Area 18 / Surrounding 1 |
| 物理技の接触:非接触 | 279:31 = 9:1 |
| 連続技 | 5種（Variable2To5 が3種、RepeatPerHit が2種） |
| learnset | 287種族・9,959行 |

データ実体は `Data/moves.json`。種族の習得表は `Data/species.json`
（`Tools/generate_learnset.py` が moves.json から自動生成）。

### 満たしている制約

いずれも `Tools/verify_attack_moves.py`（20項目）で機械検証しており、
データを触ったら必ず再実行する前提です。

**威力グリッド**
- 威力15〜120の5刻み22段階すべてに、9属性 × 物理/特殊 の各組で最低1技ある
- 同一の（属性・分類・威力）に置ける技は最大2種
- 連続技はこの判定から除外。ただし威力を数える場面では
  「単発威力 × 最大ヒット数」で換算する（例: 威力25の5回技 = 実効125）

**射程（属性ごとの上限、物理と特殊をまたいで数える）**
- Room ≤ 4 / Area ≤ 2 / Line ≤ 6 / TwoTile ≤ 3
- Adjacent のみ上限なし
- 部屋対象技は、同一属性内で威力が10以上離れていること

**接触**
- 物理技の接触:非接触 = 9:1
- Adjacent 以外の物理技は必ず非接触

## 2. 技系統（物理技のみ）

技名の**末尾**で系統を判定し、系統ごとにウェポンタグと規則が決まります。
上限は天井ではなく目標として扱い、足りない系統には条件を満たす技を改名して
編入しています。

| 系統 | 件数 | タグ | 規則 |
|---|---|---|---|
| ストライク | 10 | Strike | 威力80以下（実際は30〜75） |
| フィスト | 8 | Fist | 威力80以下（実際は60〜70） |
| ブロー | 6 | Fist | 威力80以下（実際は65〜75） |
| パンチ | 18 | Punch | 各属性2件・威力70以下・**全てに追加効果** |
| スラスト | 10 | Thrust | 無属性2＋他属性1・**全て2マス射程かつ非接触** |
| クラッシュ | 5 | Crush | **ノックバック** |
| レンド | 3 | Rend | **使用者の足元のフィールド/トラップを消去** |
| フラッシュ | 2 | Flash | **威力50固定・非接触・必中・確定急所** |

補足:
- `Fist` はフィスト系とブロー系の両方が持つ（合計14件）。旧 `ClawFist`
  タグは廃止し、この2系統からのみ付け直している
- 系統名を持つ技は必ず物理技。特殊/変化技が系統名になった場合は改名する
- 系統から外れた技は、規定のない接尾辞（スマッシュ/ビート/ピアス等）へ改名し
  タグを `None` にする

### ノックバックの仕様（クラッシュ系）

- 対象を、攻撃者から見て真後ろへ1マス押し出す
- 移動先が壁・場外・他アクターなら**誰も動かず**、押された側が最大HPの5%を受ける
- 移動先にいたのがパルなら、そのパルも**自身の**最大HPの5%を受ける
- 水源・溶岩へは、属性や生態を無視して進入する

## 3. 射程の挙動（エンジン側）

- **味方を巻き込むのは Area / FullFloor のみ**。Room / Line / TwoTile は
  味方にダメージを与えない（理由は射程ごとに異なる。下記）
- **直線・2マス射程は貫通しない**。光線上で最初にぶつかった1体だけに当たる。
  ただし味方が射線にいたときの扱いが2つで異なる
  - **直線**: 味方が射線を塞ぐ。最初にぶつかった相手が味方だった時点で技は
    不発になり、その奥の敵にも当たらない
  - **2マス射程**: 味方をその場にいないものとして素通りする。
    1マス目が味方・2マス目が敵なら2マス目の敵に命中
  - どちらも敵同士では貫通しない（2体並んでいたら手前のみ）。
    射線上に敵がいなければ不発
- **部屋対象技**は使用者と同陣営を最初から対象に含めない。廊下で使った場合は
  単体攻撃にフォールバックする
- **Surrounding（自身の周囲1マス）** は使用者を中心とした3x3。狙う先を持たない
  ため照準タイルを参照せず、Area と同じく味方も巻き込む。メガデストラクト
  専用に追加した射程で、属性ごとの上限は設けていない

## 4. 命名規則

全技名が**英語由来のカタカナ表記**（621件を一括改名済み）。旧名の音写ではなく、
技の内容から英語名を起こしています（例: 逆鱗突き →「アウトレイジスラスト」、
超電磁砲 →「レールガン」）。

技の大半は「語幹＋接尾辞」の合成語で、同じ語幹を共有する技が属性ごとに並ぶ
構造を保っています（紅蓮撃→クリムゾンストライク、紅蓮殴→クリムゾンパンチ）。
既存作品の技名リストからの借用は避けています。

## 5. 調整の経緯

本セッションは628技から出発しましたが、その前段も含めた系譜は次のとおりです。
物理技180件の取込みは現在の物理技の主体になっています（310件中178件が由来）。

| 段階 | 技数 | 内容 |
|---|---|---|
| （前段）トラップ技まで | 407 | 物理50 / 特殊335 / 変化22 |
| （前段）物理技180件の取込み | 587 | 物理230へ。**現在も178件が残存** |
| （前段）連続技・天候・変化技30種 | 628 | +5 / +6 / +30 |
| 起点 | 628 | 物理260 / 特殊310 / 変化58 |
| 射程・接触・威力の再調整 | 628 | 特殊技を全て射程持ちに。射程強化を威力で課金（直線-10 / 範囲-15 / 部屋-20） |
| 射程挙動の変更 | 628 | 部屋対象技の誤射を撤廃、直線・2マス射程を非貫通に |
| 重複整理 | 621 | 威力95以上の同威力重複と、部屋技の威力間隔を規定して7技削除 |
| 全技名の英語カタカナ化 | 621 | — |
| 属性ごとの上限導入 | **414** | 射程上限を設け207技を削除。特殊技が306→102へ |
| 技系統と威力グリッド | 581 | 8系統の規則を実装し、空いた威力枠を168技で補充 |
| スラスト縮小 | 581 | 27→10件。外れた17件は名称とタグのみ変更 |

### 途中で撤回した規則

後から入れた制約と数学的に両立しなくなったため、明示的に取り下げたものです。

- **特殊技の 直線:範囲:部屋 = 7:2:1** — 射程上限（直線は9属性×6＝最大54）では
  特殊技の7割に届かないため撤回
- **特殊技は必ず射程持ち** — 威力グリッドは1属性22段階を要求するのに対し、
  射程上限では12技しか置けないため撤回。新規技は Adjacent で追加している
- **ClawFist タグ** — フィスト系8件という上限と両立しないため廃止

### 固定例外: メガデストラクト

`megaton_self_destruct` は一括処理の対象外とする固定例外です。**以下が
再確定された基準点で、今後の一括処理で変更してはいけません。**

| 項目 | 値 |
|---|---|
| 名前 | メガデストラクト |
| 威力 | 180 |
| 射程 | Surrounding（自身の周囲1マス） |
| 命中 | 100 |
| 確殺反動 | true |

固定するのは威力という数値ではなく「確実に自滅する最終手段」という役割
そのもので、上記5項目はその役割とセットで確定しています。

経緯: 当初は「威力200・命中100・確殺反動で不変」という取り決めでしたが、
本セッションの一括処理がこれを対象に含めてしまい、射程課金で威力200→180・
射程Adjacent→Room、一括改名で名前が変わりました。指摘を受けて射程を
Surrounding へ再定義し、威力200への復元は行わず現在値で再確定しています。

この5項目は `Tools/verify_attack_moves.py` が機械検証しており、一括処理が
再び触った場合はそこで落ちます。

### 判明している副作用

特殊技が306→102→213と大きく変動した結果、learnset生成での物理/特殊の
偏り判定が反転しています（特殊寄り274種 → 物理寄り282種）。Adjacent が
無制限である一方、射程持ちの特殊技は上限に掛かるためです。種族の攻撃タイプの
性格が変わっているため、実プレイでの確認が要ります。

## 6. 関連ツール

| ファイル | 役割 |
|---|---|
| `Tools/verify_attack_moves.py` | 上記の制約を moves.json から独立に再検証（20項目） |
| `Tools/apply_move_families.py` | 技系統の規則適用と威力グリッド補充 |
| `Tools/generate_learnset.py` | moves.json から species.json の習得表を生成 |
| `Tools/verify_learnset.py` | 習得表の制約検証（10項目） |
| `Tools/export_learnsets_csv.py` | `docs/export/learnsets.csv` への書き出し |

データを変更したら
`apply_move_families.py` → `verify_attack_moves.py` → `generate_learnset.py`
→ `verify_learnset.py` → `export_learnsets_csv.py` の順に流すのが基本手順です。
