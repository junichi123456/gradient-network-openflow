
## 5. 判断が必要だった点（採った解釈と理由）

### 5-1. 数えない3件（改訂版のまま）

メガデストラクト（専用技、`FIXED` で威力180固定、learnset 規則の外）、スコーチスモッグ（制限技、`RS_SPEC`・`SPEC` に値を直書き、定員規則の外）、
ディスチャージパンチ（物理の範囲技はユーザー指示で対象外）。3件とも削除・引き下げしない（評価威力の加算は射程で決まるのでかかるが、試算で違反なし）。

### 5-2. 追加削除9個の選び方

改訂版の15個を削除した後の各属性の残り（威力の高い順）から、**属性ごとに1個（闇と虚は対で1個ずつ）**を削る（無は例外、下記）:

1. 威力の低い技から順に候補にする（同威力は id の文字コード昇順で前を残す）。
2. 削ると learnset 規則を割る技は**保護**して飛ばす。見る規則は、本数規則（#5 多数側55%・#14 無属性攻撃技2種以上・#15 特性適応技6種以上・#18 多数側の分類＝攻撃区分・
   虚の個体に虚技・攻撃技0の個体が出ない）。
3. 各属性に最低1個は残す。闇の技 X を削るときは虚の `void_X` も同時に削る。

結果（付録A-1・A-2）:

| 属性 | 追加で削除 | 保護して飛ばした技 |
|---|---|---|
| 無 | **なし**（シャッタースカイは 115 で残す） | エナジーブラスト（50）・ベアスマッシュ（30）・クリティカルエイム（25）＝ いずれも削ると #14 を割る |
| 炎 | フレイムバーンブレス（範囲65） | — |
| 水 | ウォータートルネード（部屋80） | — |
| 草 | スパインヴァイン（部屋45） | — |
| 電 | オールレンジサンダー（部屋70） | — |
| 地 | サンドストームスマッシュ（範囲65） | — |
| 氷 | アイスストーム（部屋85） | フロストバーンブレス（70）＝ 削ると #15（025 ラヴィの特性適応技が5）を割る |
| 竜 | ヤングドラゴンロア（範囲60） | — |
| 闇 | ダークスケイルスマッシュ（範囲25） | — |
| 虚 | ホロウスケイルスマッシュ（範囲25。闇と対） | — |

- **無は追加削除なし**（ユーザーの決定）。低威力3件は #14 で保護され、残る シャッタースカイ（無の範囲技で最も威力が高い、習得3種、NPC 使用なし）は削らずに
  威力115（-15）で残す。シャッタースカイを削ると、多数側の最高がこの技だった3種（083・130B・197）で #5 がどの削減量でも満たせなくなり、物理技3行の除去が要ったが、残すのでその3行は除かない。
- 削除後の残数: 無4・炎3・水3・草2・電2・地3・氷3・竜3・闇3・虚3 = **29個**（最大4は無、他は3、草・電は2）。

### 5-3. 引き下げ表（`CUT_TABLE[20]`）

- 公称 -20、基準威力35以下（残る2件: ベアスマッシュ30・クリティカルエイム25）は -10。
- 次の制約を満たすよう、公称から外れる技だけ削減量を ±5 ずらした（付録A-2 の ※。規則による4件＋ユーザー指定1件）:
  (a) 同属性・同分類で同威力2種まで（実際の威力、`rs_` 除く）、(b) §B 部屋技の同属性内の間隔10以上（実際の威力、`MV_170` 60 を含む）、
  (c) learnset 規則 #2・#3・#5・#13（評価威力）、(d) 虚 = 闇。
- ※ の4件: ボルカニックレイン -15（-20 だと評価威力の #5 を割る種が出る）、フォレストラース -10（多数側の最高が下がりすぎて #5 を割る）、
  ロアリングサンダー -15（電の部屋技 60 の `MV_170` との間隔）、フロストゲイルブレス -15（#5）。改訂版の -20 案と同じ4件。これに加えて **シャッタースカイ -15（115）はユーザー指定の例外**（計5件）。
- **シャッタースカイ 115 の影響（試算）**: 評価威力 115＋15＝130。learnset 規則 #2・#3・#5・#13 に違反なし（習得3種とも、多数側の最高として #5 の上限を 78／117 に保つ）。
  威力グリッドは 120 を超えるので無関係。無・特殊で威力115 の技は既存1件＋本技＝2件で「同威力2種まで」を満たす（範囲射程なので部屋技の間隔規則は無関係）。追加で除く行は0。
- 命中 -5 は残る29件のうち基準威力80以上の**22件**（シャッタースカイを含む）。基準威力80未満の部屋技（エナジーブラスト・シャドウアレイ・ビームスライサー・フロストバーンブレス など）が命中100のまま残るので、
  回帰の「Room・命中100以上の技」を使う項目（ワイドウォード）は成立する。

### 5-4. 評価威力（改訂版のまま）

`eval_power(m) = 実際の威力 + 加算`（射程が Room/Area/Surrounding で威力>0 の攻撃技すべて。部屋 +25・範囲 +15・周囲 +10）。learnset の #2・#3・#5（上限）・#13 と威力グリッドをこれで評価する。
しきい値・比率は変えない（評価関数の定義の変更であり緩和ではない）。

### 5-5. learnset から除く行（8行）

方針は改訂版と同じ: **どの削減量（10〜20）を選んでも評価威力の規則を割る行を除く**。改訂版の9行から次のとおり変わる（付録A-3）:

- 消える1行: 036 ドンモップ のアイスストーム — アイスストーム自体を削除するので行の除去は不要（削除技の行として消える）。
