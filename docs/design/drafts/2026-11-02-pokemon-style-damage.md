# ダメージ計算式をポケモン式に置き換える — 仕様書（確定）

- ユーザー指示（2026-11-02）: 「ダメージ計算式を、ポケモンのダメージ計算式を参考に見直してみてください。ダメージ = ((((レベル × 2 ÷ 5 + 2) × 技の威力 × 攻撃側のこうげき(またはとくこう) ÷ 防御側のぼうぎょ(またはとくぼう)) ÷ 50) + 2) × 乱数」
- 確認の回答: **除数は 50（そのまま）／乱数 0.85〜1.00 を入れる／直前の「最終ダメージ +1」は外す／全モード（対戦含む）に適用**。
- ブランチ `claude/mystery-dungeon-roguelike-egnzjt`。実装者は git を使わない（検証者がコミット）。ビルドは `dotnet build MysteryDungeonRoguelike.csproj` を先に。回帰は NG 行数（現在 259 項目、6回連続）。Python は `/usr/bin/python3`。
- 現行（置き換え対象）: `Scripts/Combat/DamageCalculator.cs`（`Calculate`: 有効攻撃/防御/威力 → `A²/(A+D) × 威力/100` → 倍率 → floor、`FlatFinalDamageBonus`・`ApplyFlatFinalBonus`）、`DamageContext.cs`、`Scripts/Turn/AttackAction.cs`（`StrikeTarget` の +1、防御側軽減8か所の `Max(1, floor(...))` を外した変更）、NPC の評価（`Scripts/Battle/NpcOpponent.cs` の `ScoreAttack` 等が `Calculate` を呼ぶ場合）、回帰のベンチマーク（`BattleTestScene`）、`docs/design/pvp_spec.md` §36。

## 1. 新しい式
```
基本 = floor( floor( floor(Lv×2/5) + 2 ) × 有効威力 × 有効攻撃 / 有効防御 ) / 50 ) + 2
```
（ポケモンと同じく整数の切り捨てを段ごとに行う。`Lv` は**攻撃側のレベル**、`有効攻撃/有効防御` は現行の `effAtk`/`effDef`（固定加算→倍率の順、`max(0,…)`。防御0の0除算は防御を1にして避ける）、`有効威力` は現行の `effPower`（威力＋固定加算、×威力倍率）。物理技は A 対 B、特殊技は C 対 D のまま。）
```
最終 = 基本 × 乱数 × 相性倍率 × 一致属性補正 × 急所(1.5) × 竜の倍率 × (1−属性耐性カット) × (1−パーティ属性カット)
ダメージ = floor(最終)。ただし 倍率の積 > 0 かつ 威力 > 0 の命中ヒットは最低 1。
```
- **乱数**: 0.85〜1.00 の16通り（`(85 + 乱数 0..15) / 100`）。**戦闘で使う既存の乱数（命中・急所の判定と同じ RNG）から、ダメージを決めるヒットごとに1回**引く（ネットワーク対戦・固定シードで両側が同じ順序で消費すること。引く位置はミス・無効の判定の**後**にして、無駄に流れを変えない）。同じシードなら同じ結果になる（再現性は保つ。ただし旧結果とは別物になる）。
- `DamageContext` に `RandomFactor`（既定 1.0）を足す。**ベンチマーク・検査・NPC の評価では 1.0（または期待値 0.925）を渡す**（実戦の `AttackAction` だけが乱数を渡す）。
- **直前の変更を戻す**: `FlatFinalDamageBonus`/`ApplyFlatFinalBonus`/`StrikeTarget` の +1 を削除し、防御側軽減8か所（やけど、耐性特性、Crit Shell、Weakness Cut、きぬぬい、わたほうし、むれのいちいん、Build-Up）の `Max(1, floor(...))` を +1 導入前の挙動に戻す。吸収・回復（あくむのひとみ・あくい）は「実際に与えたダメージ」を基準に1つの値で揃える（前回、+1 の前後で1HPずれていた件はこれで解消）。
- 継続ダメージ・地形・反動・割合/固定ダメージ・自爆など、ダメージ計算パイプラインを通らない経路は**変えない**（前回の一覧に従う）。
- 倍率の計算順・丸め: `基本`（整数）に 乱数→各倍率を float で掛け、最後に1回 floor（ポケモンの段ごとの切り捨ては近似でよい。実装者が選んでよいが、選んだ内容を報告）。

## 2. 期待値（ベンチマークの更新）
- Lv50、実数値 A=D=75、威力35（プレーンバレット）、乱数 1.0 → `floor(floor(22×35×75/75)/50)+2 = 17`（770÷50=15、+2）。HP130 なら 130÷17 ≒ 7.6 発。乱数 0.85 なら `floor(17×0.85)=14`。
- Lv5、A=D=12、威力25 → `floor(floor(4×25×12/12)/50)+2 = 4`（HP22 で約5.5発）。
- ヘッダコメントのベンチマーク記述（攻70・防70・威力20 → 7、威力35 の同型 → 13/14 の説明）を、新式の値と「Lv5〜Lv100 で決着が約5〜8発」の性質に書き直す。

## 3. 影響（実装者が更新）
