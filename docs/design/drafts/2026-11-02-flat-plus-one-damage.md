# 最終ダメージへの定数 +1 — 仕様書（確定）

- ユーザー指示（2026-11-02、確認の回答原文）: 「最終ダメージに定数+1を加算する。あらゆる補正、特性、持ち物、場の状況の影響の最後に加算される定数で、これによりダメージを与えうる状況では必ず1ダメージが保証される。これは複数回ヒットの技ではヒットのたびに発生するものとみなす。」
- 背景: 低レベル（Lv1〜5）では実数値が「種族値×2×Lv/100＋5」で攻撃・防御が拮抗し、初期技（威力15〜25）のダメージが 1〜2、敵HP 12〜18 に対し約10発かかる。前段の調査で `DamageCalculator.Calculate` の末尾が `Max(1, …)` で 0 にはならないことを確認済み。**この変更は対戦（PvP）にも及ぶ**（ユーザーが承知のうえで選択）。
- ブランチ `claude/mystery-dungeon-roguelike-egnzjt`。実装者は git を使わない（検証者がコミット）。ビルドは `dotnet build MysteryDungeonRoguelike.csproj` を先に。回帰は NG 行数（現在 259 項目、6回連続）。

## 1. 変更内容
1. **ダメージ確定の最後に +1**: ダメージ計算（`Scripts/Combat/DamageCalculator.cs`）と、その後に `Scripts/Turn/AttackAction.cs` 等で足される加算・減算・特性・持ち物・天候・場の補正・防御側の軽減など**すべてを適用し終えた後**（HPから引く直前）に、1ヒットごとに +1 を足す。実装位置は「ダメージを対象に適用する共通の最終点」にする（複数ヒットの技はヒットごとに、体当たりも含む）。
2. **0 になる場合には足さない**（「ダメージを与えうる状況」のみ）: 相性無効（倍率0）、特性による吸収・無効、まもる/プロテクションなどの無効化、命中しなかった攻撃、威力0の変化技、無敵状態、固定の0。これらは +1 しない（ダメージ0のまま、既存の挙動を保つ）。
3. **`DamageCalculator.Calculate` 末尾の `Max(1, …)`（最低保証1）は外し、+1 が最低1の保証を担う**形にする（相性無効などで元から0を返す経路は 0 のまま。`Max(1,…)` を外すことで、切り捨てで 0 になった命中ヒットは +1 で 1 になる）。丸めの途中経過（床）の扱いは現行のまま。
4. **対象外**: 毒・やけど等の継続ダメージ、地形ダメージ、反動、満腹度ダメージ、割合ダメージ・固定ダメージ技（ダメージ計算パイプラインを通らないもの）。見つけた対象外の経路と、パイプラインを通るが除外したものを報告に一覧で載せる。
5. 設計の置き場を1か所にして、将来の調整（+1 を定数化）がしやすいよう、定数 `FlatFinalDamageBonus = 1` を `DamageCalculator` か隣接する定数ファイルに置く。
